EVENT HUB - UPDATED IA-3 DEMO

1. Extract the ZIP completely.
2. Open index.html in a browser. Keep all files in the same folder.
3. Organizer: Create Event -> the event is saved in localStorage and appears in All Events, search, details and calendar.
4. Attendee: open an event -> Register Now -> enter full name, register number, email and 10-digit phone -> Confirm Registration.
5. My Registrations shows attendee details and ticket reference.
6. Student account registration: register.html (also signup.html); demo sign-in: signin.html.
7. Theme toggle and calculator are available on pages with the shared script.js. Chatbot searches built-in and organizer-created events.
8. Data is stored in this browser using localStorage. Clearing browser data removes demo events/registrations. This is a front-end demonstration, not a secure production account or database.
9. GitHub push and Vercel deployment, report printing/signatures, Google Form submission, screenshots and video are manual submission tasks.
